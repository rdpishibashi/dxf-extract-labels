# DXF Extract Labels - 機器符号抽出

DXFファイルからテキストラベルを抽出し、Excel形式で出力するStreamlitアプリケーションです。

## 機能

- **複数ファイル対応**: 複数のDXFファイルを一括処理
- **ラベル抽出**: 図面枠内・図面情報枠（タイトルブロック、幾何検出）外の全ラベルを
  抽出し、Reference Designator の3候補パターンに一致するものには「機器符号候補」列に
  `Y` を付与する（一致しないラベルは空欄のまま。除外や確認は行わない）
- **図面番号・タイトル・サブタイトル抽出**: 図番・流用元図番・タイトル・サブタイトルを
  常に自動抽出（ラベルベース・座標ベース）
- **複数図面対応**: 1ファイルに複数図面がある場合、全図面枠を対象
- **矩形領域抽出**: 図面枠内の矩形（直交ポリゴン）領域を検出し、領域内ラベルに領域名を付与（「領域選択オプション」）
- **端子一覧抽出**: タイトルが「UNIT内結線図」の図面を対象に、TBで始まる端子台ラベルに
  対応する矩形（LINE+CIRCLEで構成）を検出し、矩形内の端子番号を「TB List」シートに出力
- **Excel出力**: 統計情報とラベル一覧をExcel形式で出力（Summary以外の全シートに
  オートフィルタ設定済み）
- **自動集計**: ファイルごとの個別シートとサマリーシートを生成

## 使用方法

### 基本的なワークフロー

1. **ファイルのアップロード**: 複数のDXFファイルをアップロード可能
   - ドラッグ&ドロップまたはファイル選択
   - 複数ファイルの同時アップロード対応

2. **オプション設定** (任意):
   - **領域を検出**: OFF（既定）は通常モード。ONにすると矩形領域付きでラベルを
     抽出できる（後述）
   - **端子一覧を抽出**: タイトルが「UNIT内結線図」の図面（サブタイトルが「TB COMPONENT」
     の図面を除く）を対象に、TBで始まる端子台ラベルに対応する矩形を検出し、矩形内の
     端子番号を「TB List」シート（抽出ラベル一覧シート直後）に出力する
   - **並び替え**: 昇順、降順、並び替えなしを選択

   図面枠内・図面情報枠外の全ラベルが常に抽出され、機器符号（Reference Designator）
   パターンに一致するものには「機器符号候補」列に `Y` が付く（一致しないラベルは
   空欄）。図番・流用元図番・タイトル・サブタイトルも常に抽出される。
   - 候補パターン例: `CNCNT`, `FB`（英字のみ）、`R10`, `CN3`, `AAC1B4-07`（英字+数字+ハイフン任意）、
     `CN-IF2-1`（英字-英字+数字）、`FB()`, `MSS(MOTOR)`, `R10(2.2K)`（括弧付き、括弧より前で判定）

3. **ファイル処理**: 「ラベルを抽出」ボタンをクリックすると抽出とExcel生成が
   直ちに行われます

4. **結果のダウンロード**: Excelファイルをダウンロード
   - ダウンロード後は「新しい抽出を開始」ボタンが青色になります
   - 「新しい抽出を開始」をクリックすると、アップロード済みファイルがクリアされます
     （オプション設定は保持されます）

### 出力ファイル

デフォルトのExcelファイル名: `extracted_labels.xlsx`

Excelファイルの構成（通常モード・領域モード共通）:
- **Summaryシート**: 全ファイルの抽出結果概要（8列固定、オートフィルタなし）
  - ファイル名、総抽出ラベル数、機器符号候補ラベル数、ページ数、検出領域数
  - 図番、タイトル、サブタイトル
- **抽出ラベル一覧シート**（旧`Total`）: 全ファイル横断のラベル・個数・図番集計
  （「機器符号候補」列が「ラベル」列の直左に付く）
- **各ファイルシート**: 個別ファイルのラベル一覧（「機器符号候補」列付き。
  領域モードでは「領域」列も付く）

Summary以外の全シートにオートフィルタが設定されます。

### 矩形領域抽出（領域選択オプション）

図面枠（太さ100の線で囲まれた枠）内の矩形領域を検出し、領域内ラベルに領域名を付与します。
オプションの「領域を検出」にチェックを入れると使えます（既定OFF）。

1. オプションの「領域を検出」にチェック（ONの間は「ラベルを抽出」ボタンは表示されず、
   「領域を検出」ボタンのみが表示されます）
2. （任意）「領域検出の詳細設定」で検出パラメータを調整し「設定完了」
   - 「抽出したい領域名の先頭文字列（カンマ区切り・複数可）」を指定すると、名称
     候補がその文字列で始まる領域は面積比の閾値を満たさなくても抽出対象になります
     （前方一致。全角/半角は区別しません）
3. 「領域を検出」をクリック（検出が終わると「領域を検出」ボタンは消えます）
4. 「領域一覧」に、検出された全ファイル・全領域の名称候補（複数候補を持つ領域も
   含む）が重複なくABC順のチェックボックスとして一覧表示されます（ブラウザ幅に
   応じて自動的に折り返す）。抽出したい領域名にチェックを入れ（複数選択可）、
   「領域選択を完了」をクリックします。
   - ある領域のチェック済み候補が**ちょうど1件**なら、その名称で自動的に抽出されます
   - チェック済み候補が**0件**の領域は抽出されません（次の「領域の確認」にも
     表示されません）
   - チェック済み候補が**2件以上**残る領域は、次の「領域の確認」でどれを採用するか
     個別に選ぶ必要があります
   - チェックを変更すると「領域選択を完了」は取り消され、再度クリックするまで
     以降のセクションは表示されません
5. 「領域の確認」では、「領域一覧」でチェック済みの候補が2件以上残っている領域
   だけが表示されます（該当領域が無いファイルは表示自体されません）。各領域の
   チェック済み候補のみをチェックボックスで表示し、1つ選択します（各領域の
   📐角座標も確認可能）
   - ファイル名の直下に「図番：… / タイトル：… / サブタイトル：…」が表示されます
   - 候補群の末尾の「（領域選択しない）」にチェックを入れると、この領域にはどの
     ラベルも割り当てられません
6. 「ラベルを抽出」（「領域選択を完了」を押すと表示されます）→「Excelをダウンロード」
   （`領域` 列・`領域一覧` シート付き）
   - 抽出完了後は、オプション・詳細設定・「領域一覧」・「領域の確認」の内容は
     表示されたまま操作できなくなります（振り返り用）。設定を変更したい場合は
     「新しい抽出を開始」でリセットしてください
   - `抽出ラベル一覧` シートでは、領域所属を問わず全ファイル横断でラベルと個数を確認できます
   - `領域一覧` シートには、確定・未確定を問わず**検出した全領域**が
     `ファイル名`・`領域名`・`面積率[%]`・`領域内ラベル数`・`領域内機器符号候補数`
     の5列で記載されます（同一ファイル・同一領域名がページ横断で複数ある場合は
     合算されるため、面積率が100%を超えることがあります）。名称が未確定の領域は
     候補名がカンマ区切りで列挙されます
   - `領域別ラベル一覧` シートでは、**確定済み**の領域名ごとに全ファイル横断で
     ラベルと個数を確認できます（同名の領域は複数ファイルにまたがって合算されます。
     「機器符号候補」列付き）

### 端子一覧抽出

タイトルが「UNIT内結線図」の図面（サブタイトルが「TB COMPONENT」の図面＝端子台の
全端子番号一覧ページを除く）を対象に、TBで始まりその直後に英大文字・数字が1文字
以上続くラベル（例: `TB001`、`TBN241 (24A)`。`TB取付板`のようにTBの直後が漢字等の
ものは対象外）に対応する矩形（LINE+CIRCLEで構成、CIRCLEによる橋渡しが1箇所以上
ある矩形のみ）を検出し、矩形内の端子番号（数字のみのラベル）を抽出します。

1. オプションの「端子一覧を抽出」にチェック
2. 「ラベルを抽出」→「Excelをダウンロード」
   - `TB List` シート（`端子台` / `端子No.` / `図番`）が `抽出ラベル一覧` シート直後
     （領域モードでは `領域別ラベル一覧` 直後）に追加されます
   - **「端子台」でユニーク**をとります。同じ端子台名が複数ファイルにまたがって
     登場する場合、端子番号・図番を1行に統合します（例:
     `TBN241 (24A) | 1, 5, 6, 29, 30, 31 | EE6492-039-38A, EE6892-039-03A`）
   - 「端子No.」で同じ番号が複数回登場する場合は `7(2)` のように件数を
     カッコ内に表示します
   - 「端子台」はABC順、複数の「図番」もABC順にソートされます
   - 候補パターンには一致したが対応する矩形が見つからないラベルは、
     一覧の末尾に1行空けたうえで「端子台」欄に「端子検出不可」、
     「端子No.」欄にそのラベル、「図番」欄にそのファイルの図番として
     記載されます
